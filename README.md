# Discord Ticket Bot 🎫

بوت تكت جاهز ومتكامل لـ Discord باستخدام **discord.js v14**.

## 🚀 طريقة التشغيل

1. **فك الضغط** عن الملف.
2. قم بتسمية ملف `.env.example` إلى `.env` وضَع بيانات البوت الخاصة بك (TOKEN, CLIENT_ID, GUILD_ID, SUPPORT_ROLE_ID).
3. قم بتثبيت الحزم:
   ```bash
   npm install
   ```
4. قم بتسجيل أوامر الـ Slash:
   ```bash
   node deploy-commands.js
   ```
5. شغل البوت:
   ```bash
   npm start
   ```
